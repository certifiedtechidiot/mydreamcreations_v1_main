# Dream Creation Events — Luxury Wedding Planning & Decor

A bespoke, responsive luxury wedding planning website designed for **Dream Creation Events** ([@dream_creation_event_](https://www.instagram.com/dream_creation_event_)), modeled with pixel-level precision after the [Pinterest Wedding Planner Design Reference](https://in.pinterest.com/pin/1133570168748937080/).

---

## 🎨 Design Reference & Visual Architecture

This website replicates the layout, typography, colors, and structure of the reference design:
* **Palette:** Sophisticated Olive / Sage Green (`#4E5641`), warm ivory & blush backgrounds (`#FAF4EE`), and dark charcoal typography (`#272922`).
* **Typography:** `Cormorant Garamond` (editorial Roman serif) + `Plus Jakarta Sans` (modern clean body).
* **Reference Image:** Stored in this repository as [`design_reference.jpg`](design_reference.jpg).

## 🚀 Running Locally

No build tools or Node dependencies required. Simply open with any static server:

```bash
# Using Python
python3 -m http.server 8000

# Open in your browser
http://localhost:8000
```

## 📱 Live GitHub Pages Deployment

To enable GitHub Pages:
1. Go to repository **Settings** > **Pages**
2. Under **Build and deployment** > **Source**, select `Deploy from a branch`
3. Set Branch to `main` and folder to `/ (root)`
4. Save — your website will be live at `https://certifiedtechidiot.github.io/mydreamcreations_v1_main/`
